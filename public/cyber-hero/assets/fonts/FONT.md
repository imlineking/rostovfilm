# Шрифт фильма Cyber Scum

Используется **Marske**, файл `Marske.ttf`, предоставленный пользователем 30 октября 2026 года. Пользователь сообщил, что уже установил его в Windows.

Шрифт лежит в блоке по относительному пути `assets/fonts/Marske.ttf` и подключён локально через `@font-face` в `hero.css`. CSS-переменная `--film-font` задаёт семейство для названия фильма и заголовков. Установка шрифта на сервер или компьютер посетителя не требуется.

При переносе копировать **всю папку `dist`**, включая `assets/fonts`, `assets/fonts/FONT.md`, медиаматериалы и логотип. Названия и регистр файлов сохранять. Это исходный файл пользователя без изменения контуров или встраивающих флагов.

Основной текст оставлен в Golos Text для читаемости мелких описаний; заголовки фильма — Marske, normal 400, без искусственного курсива/жирности.

Внутреннее имя файла: `Marske Regular`, версия с кириллицей. Автор оригинала Kash Singh; кириллические знаки — Sergiy Tkachenko / 4thfebruary. Файл не модифицировался.

Страница автора: https://www.behance.net/gallery/21677209/Marske-FREE-FONT . Сохранение файла в блоке не заменяет условия автора; предоставленный файл является источником пользователя.

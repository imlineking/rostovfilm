# rostovfilm

Сайт киностудии «Ростовфильм» — Ростов-на-Дону. Одностраничный лендинг: о студии, услуги, проекты, команда, форма заявки с капчей.

## Технологии

- Next.js 16 (App Router) + TypeScript
- Tailwind CSS 4 + shadcn/ui
- framer-motion (анимации)
- Prisma ORM + SQLite (заявки из формы)
- Уведомления: e-mail (SMTP) + мессенджер MAX

## Запуск

```bash
bun install
bun run dev
# http://localhost:3000
```

Продакшен-сборка: `bun run build && bun start`. Для деплоя используйте именно production-сборку, а не dev-сервер: поведение dev и prod может отличаться (один из багов капчи был связан именно с минификацией в prod).

## Переменные окружения

### `NEXT_PUBLIC_SITE_URL` (рекомендуется для деплоя)

Публичный адрес сайта, по которому он доступен из интернета.

- **Формат:** полный URL без слэша на конце.
- **Зачем нужна:** от неё строятся все абсолютные ссылки на проде:
  - `canonical` и `metadataBase` в `<head>`;
  - Open Graph / Twitter Card (`og:url`, ссылки на картинки);
  - `sitemap.xml` и `robots.txt`;
  - JSON-LD (Organization);
  - ссылки «открыть сайт» в уведомлениях о новых заявках.
- **Где задать:** в переменных окружения деплоя (панель хостинга, Docker, systemd и т.п.) или локально в `.env.local`:

```bash
NEXT_PUBLIC_SITE_URL=https://rostovfilm.ru
```

- **Если не задана:** используется значение по умолчанию `https://rostovfilm.ru`. Если сайт фактически доступен по другому адресу — canonical, OG-ссылки и sitemap будут указывать на неверный домен, что плохо для SEO и превью в мессенджерах.
- **Важно:** `NEXT_PUBLIC_*` переменные зашиваются в клиентский бандл при сборке — меняйте их **до** `bun run build`, а не после.

### Остальные переменные

Секретные переменные (пароль SMTP, токен бота MAX, секрет капчи и др.) задаются в `.env.local` и **не коммитятся** в репозиторий — значения смотрите в закрытом доступе у владельца проекта. В репозитории лежит только `.env` с безобидным локальным `DATABASE_URL`.

## Деплой

- Репозиторий: https://github.com/imlineking/rostovfilm
- Перед выкладкой не забудьте задать `NEXT_PUBLIC_SITE_URL` (см. выше) и секретные переменные из `.env.local`.
- `sitemap.xml`, `robots.txt`, `manifest.webmanifest` и OG-картинки генерируются автоматически и настроятся на домен из `NEXT_PUBLIC_SITE_URL`.

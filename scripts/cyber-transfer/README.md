# Ростов Фильм — видеошапка Cyber Scum

Автономный HTML/CSS/JavaScript без сборки и сторонних JS-библиотек. Открывайте через HTTP-сервер из `dist/`, например `python -m http.server 4173 --directory dist`.

Четыре сцены: новый ролик Raven (первым, по указанию пользователя), предыдущий ролик, GIF-эфир президента (конвертирован в MP4) и изображение киборга с медленным движением. Компактный номерной селектор и play/pause справа. Нижней полосы, миниатюр и верхней кнопки «О демо» нет. Управление: номера, клавиши ← → и свайп/перетаскивание. Пауза останавливает видео, движение изображения, автопереключение и прогресс. Кнопка отрывка открывает реальный клип со звуком после клика; Escape закрывает окно. `prefers-reduced-motion` и `?motion=reduce` включают статичные постеры и отключают автоматическое движение.

Для замены материалов: `dist/assets/cyber-0N.*`; тексты и длительность — `dist/hero.js`; оформление — `dist/hero.css`. Фон всегда без звука и автоматически играет при загрузке; ролики в модальном окне сохраняют исходную звуковую дорожку. Исходный красно-белый PNG логотипа скопирован без перерисовки.
